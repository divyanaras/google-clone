# Google Clone

A modern, fully functional Google homepage clone with advanced features, animations, and enhanced user experience.

## Features

### 🎨 Visual Design
- Pixel-perfect Google homepage replica
- Subtle gradient backgrounds and glassmorphism effects
- Smooth micro-animations and transitions
- Dark mode with seamless switching
- Fully responsive design for all devices

### 🔍 Search Functionality
- Interactive search bar with suggestions
- Voice search icon
- "Google Search" and "I'm Feeling Lucky" buttons
- Keyboard shortcuts support
- Search history and autocomplete

### 🧭 Navigation
- Gmail and Images links
- Apps menu dropdown
- Sign in button
- Profile circle with user avatar
- Language switcher

### 🌙 Themes
- Light/Dark mode toggle
- Smooth color transitions
- Persistent theme preference
- Custom CSS properties for easy theming

### ♿ Accessibility
- ARIA labels and semantic HTML5
- Keyboard navigation support
- Screen reader compatibility
- Focus management
- High contrast mode support

## Quick Start

1. Clone or download the project
2. Open `index.html` in your web browser
3. Enjoy the Google homepage experience!

## Usage

### Basic Search
- Type in the search bar and press Enter or click "Google Search"
- Click "I'm Feeling Lucky" for random search
- Use arrow keys to navigate suggestions

### Keyboard Shortcuts
- `Tab` - Navigate between interactive elements
- `Enter` - Submit search or select suggestion
- `Escape` - Close dropdowns
- `Ctrl/Cmd + K` - Focus search bar
- `Ctrl/Cmd + D` - Toggle dark mode

### Dark Mode
- Click the dark mode toggle in the header
- Your preference is saved in localStorage
- Smooth transition between themes
